# Working rules

## Ask before building when anything is unclear

Never build, create or change anything when the instructions are unclear or you are unsure what is needed. Ask first.

- If a request could refer to something that already exists (an artifact, file, app or project with that name), check for it first. For example, "patrol board" means the existing pinned **Patrol Board** artifact, so don't make a new one.
- If it is still ambiguous after checking, ask one short question before doing any work.
- Only start building once the instruction and its target are clear.
